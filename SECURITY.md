# Security Policy

## Supported Versions

Versions of your indice platform that are
currently being supported with security updates.

| Version  | Supported          |
| -------- | ------------------ |
| 8.x.x    | :white_check_mark: |
| 7.46.0   | :white_check_mark: |
| < 7.46.0 | :x:                |

## Reporting a Vulnerability

To privately report a security vulnerability, please create a security advisory in the [repository's Security tab](https://github.com/indice-co/Indice.Platform/security/advisories).

Further details can be found in the [GitHub documentation](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability).
